# 礼簿 · libu.quickso.top

一个免安装、离线优先的 Vue 3 电子礼簿。数据使用 IndexedDB 保存，不依赖业务后端。

## 开发

```bash
npm install
npm run dev
```

## 数据原则

- 礼金金额以分为单位存储，避免浮点计算误差。
- 事件、礼金和审计记录通过 IndexedDB 事务写入。
- 撤销记录保留审计痕迹；不会直接物理删除。
- Excel（`.xlsx`）用于本地备份、报表和批量录入。

## 发布

```bash
npm run build
```

将 `dist/` 部署到任意静态站点即可。应用不需要后端；同一浏览器和来源下的数据保存在本机。跨设备迁移时，请先在目标设备创建对应礼簿，再导入 Excel。
