# 礼簿 · libu.quickso.top

一个面向婚礼、寿宴、升学宴、乔迁等场合的离线优先电子礼簿。保留传统竖排礼单的书写形式，同时提供 Excel 导入导出、打印/PDF 和副屏展示。

**线上访问：<https://libu.quickso.top>**

## 隐私与数据存储

线上版本只提供静态网页文件，**不设账号、不设业务后端、不接收、不上传、不保存任何礼簿录入数据**。

- 活动、来宾姓名、礼金、关系、收款方式和备注均保存在当前浏览器的 IndexedDB 本地数据库。
- 数据仅存在于当前浏览器和当前访问来源中；线上站点、开发者和其他用户无法读取这些数据。
- 使用 `libu.quickso.top` 与直接打开本地 HTML 属于不同来源，二者的数据彼此独立。
- 清除浏览器站点数据、使用无痕窗口或更换浏览器/设备，都可能导致本地记录不可见。活动结束前请导出 Excel 留存。

## 使用方式

### 在线使用

访问 <https://libu.quickso.top>，创建礼簿后即可录入。无需安装 Windows、macOS 或其他桌面应用。

### 下载后本地使用

从 [Releases](https://github.com/quicksoo/libu.quickso.top/releases) 下载最新的 `libu.quickso.top.html`，用现代浏览器直接打开即可使用。发布包只有一个 HTML 文件，适合断网现场、内网环境或需要完全本地操作的场景。

> 建议首次使用时选定一种方式并持续使用。线上站点和本地 HTML 的数据不会自动合并。

## 已实现功能

### 传统礼单录入

- 每页 12 列竖排礼单，姓名和礼金大写金额分区展示。
- 支持姓名、礼金、收款类型、关系和备注。
- 常用礼金快捷项：`50`、`100`、`200`、`300`、`500`、`600`、`800`、`1000`、`888`、`666`。
- 常用关系快捷项：朋友、同学、乡党、亲戚、同事、战友、师生、领导、客户、亲家。
- 礼金按录入顺序追加；每页满 12 笔后自动进入下一页。
- 支持按姓名/备注搜索、按收款类型筛选、点击礼单记录修改或撤销。

### 实时统计与副屏

- 主屏和副屏均展示：总金额、总人数、本页金额、本页人数。
- 点击“副屏展示”可打开与主屏礼单相同样式的独立展示窗口。
- 主屏录入、修改、撤销、导入或翻页后，副屏实时同步数据和当前页码。
- 副屏同步依赖同一浏览器、同一访问来源下的 `BroadcastChannel`，无需服务器；可将副屏窗口拖到投影仪或电视屏幕。

### Excel 与打印

- 导出当前活动为 `.xlsx`，包含“礼金明细”和“汇总”工作表。
- Excel 文件名使用“活动名称 + 导出时间”；录入时间按本地格式导出，例如 `2026-10-14 09:30:00`。
- 支持导入 Excel 礼金明细到当前礼簿。
- 支持打印或另存为 PDF：横向 A4、传统礼单分页、封面“礼簿本”、活动名称和活动时间。
- 喜事使用红色礼单主题；庄重场合使用蓝白主题，打印封面与礼单同步适配。

## 操作建议

1. 活动开始前创建礼簿，填写活动名称、日期、记账人和礼簿风格。
2. 录入时优先使用金额和关系快捷项，提高登记速度。
3. 需要投影时点击“副屏展示”，将弹出的副屏窗口移至外接显示器。
4. 活动结束后点击“导出 Excel”或“备份 Excel”保存记录。
5. 需要纸质存档时点击“打印/PDF”，在浏览器打印窗口中选择“另存为 PDF”或目标打印机。

## 常见问题

### 需要安装软件或创建账号吗？

不需要。可直接访问线上站点，也可下载单个 `index.html` 在本地浏览器打开。

### 线上使用时，礼簿数据会上传到服务器吗？

不会。应用没有礼簿数据接口，录入数据只写入当前浏览器本地数据库；线上页面只负责加载应用代码。

### 为什么换电脑或换浏览器后看不到记录？

礼簿默认保存在浏览器本地，不做云同步。请在原设备导出 Excel，在目标设备先创建对应礼簿后再导入 Excel。

### 副屏为什么没有同步？

主屏和副屏需要使用同一个浏览器、同一个访问来源。例如都打开线上站点，或都打开同一份本地 HTML。请允许浏览器打开副屏弹窗，并避免用一个线上站点窗口搭配另一个本地 HTML 窗口。

### 浏览器清理数据会影响礼簿吗？

会。清除该站点数据、使用浏览器清理工具或无痕窗口都可能删除或隔离本地礼簿。请定期导出 Excel。

## 本地开发与发布

环境要求：Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

构建单文件发布包：

```bash
npm run build
```

构建完成后，`dist/` 中仅保留 `index.html`，可直接部署到任意静态网站托管服务，或单独分发给用户本地打开。项目不需要数据库、应用服务器或 API 服务。

### GitHub Release 发布

仓库的 `.github/workflows/release.yml` 会在推送版本标签（例如 `v1.0.0`）时自动构建，并创建 GitHub Release，上传单文件资产 `libu.quickso.top.html`。

```bash
git tag v1.0.0
git push origin v1.0.0
```

用户可从 [Releases](https://github.com/quicksoo/libu.quickso.top/releases) 下载对应版本；最新版本也可使用固定地址：

<https://github.com/quicksoo/libu.quickso.top/releases/latest/download/libu.quickso.top.html>

## 技术说明

- Vue 3 + TypeScript + Vite
- Dexie / IndexedDB 本地事务存储
- ExcelJS 读写 `.xlsx`
- BroadcastChannel 主副屏实时同步
- 金额以“分”存储，避免浮点计算误差
